Cloudflare Worker Ready

一个简单、可直接部署的 Worker 静态站点

这个项目通过 Cloudflare Worker 托管静态资源，不依赖构建框架。仓库同步到 GitHub 后，Cloudflare 可以直接执行 Wrangler 部署。

打开 Cloudflare 查看部署步骤

最小结构

静态资源集中放在 public 目录，避免把仓库内部文件误发布到公网。

Worker 托管

Worker 入口把所有请求转发给静态资源绑定，部署链路与当前 Cloudflare 界面一致。

可控 404

访问不存在的路径时，Worker 会统一返回自定义 404 页面。

部署步骤

  1. 把当前仓库推送到 Gitee，并确认已镜像到 GitHub。
  2. 在 Cloudflare Worker 创建页选择对应的 GitHub 仓库。
  3. Build command 留空，Deploy command 填 npx wrangler deploy。
  4. Cloudflare 会读取 wrangler.toml 并发布 public 目录中的静态资源。
