Cloudflare Pages Ready

一个简单、可直接部署的静态站点

这个项目不依赖构建工具，不需要 Node 服务。把仓库连接到 GitHub 后，Cloudflare Pages 直接读取仓库根目录中的静态文件即可上线。

打开 Cloudflare 查看部署步骤

零构建

保留最少文件，Cloudflare Pages 可直接托管，无需打包命令。

自动部署

GitHub 仓库有新提交时，Cloudflare 自动拉取并发布新版本。

静态友好

首页与 404 页面都使用原生 HTML 和 CSS，部署行为稳定可预期。

部署步骤

  1. 把当前仓库推送到 GitHub。
  2. 在 Cloudflare Pages 中选择 Connect to Git，并绑定这个 GitHub 仓库。
  3. Production branch 选择你实际使用的分支，例如 main。
  4. Build command 留空，Build output directory 填 . 或留空。
  5. 首次部署成功后，使用 Cloudflare 提供的 pages.dev 域名访问站点。
